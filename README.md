# IL Helper · Windows x64

在[官网下载页](https://fieldwork-studio.pages.dev/download/)或[最新发行页](https://github.com/wcs2009/IL-Helper-Releases/releases/latest)下载文件名以 `setup.exe` 结尾的安装包。

1. 双击安装包，选择一个可写的父目录。
2. 在新建的 `IL Helper` 文件夹中运行 `IL-Helper.exe`。
3. 首次使用先申请账号，管理员审批后即可联网登录。

普通用户可查看资料和离线星系沙盘。VIP 可使用实时星图、扫图和自动化。管理员可审批申请、调整等级和停用账号。任务在用户电脑上运行。

已有安装请使用客户端更新。每个发行版本同时提供更新 ZIP 和两个下载文件各自的 SHA-256，可用 PowerShell 的 `Get-FileHash` 核对。

点击登录页的“申请账号”，在独立表单填写账号和密码。云端确认后会显示审批状态。若提交时断线，可使用相同凭据再次提交。
